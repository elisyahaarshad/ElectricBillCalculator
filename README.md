
# ⚡ Electric Bill Calculator

An Android mobile application developed to calculate monthly electricity bills based on electricity consumption (kWh) and rebate percentage.

## 📱 About the Application

Electric Bill Calculator helps users calculate their monthly electricity charges quickly and easily. Users can select a month, enter electricity usage, and choose a rebate percentage to calculate the total bill.

## ✨ Features

- Calculate electricity charges based on progressive tariff rates
- Select billing month (January – December)
- Enter electricity consumption (1 – 1000 kWh)
- Apply rebate from 0% to 5%
- View total charges and final bill after rebate
- Save bill records using SQLite database
- View bill history
- Edit and delete saved records
- View detailed bill information
- About page with developer information

## ⚡ Electricity Tariff Rates

| Electricity Usage | Rate (RM/kWh) |
|---|---:|
| First 200 kWh | RM 0.218 |
| Next 100 kWh | RM 0.334 |
| Next 300 kWh | RM 0.516 |
| Next 300 kWh | RM 0.546 |
